## Спайк M0: вибір провайдерів STT і LLM

### STT — 2026-10-28 — A

- **Рішення:** Soniox (потоковий WebSocket API напряму через `ClientWebSocket`, без бібліотеки).
- **Як вибирали:** повного порівняння Soniox / Deepgram / OpenAI, передбаченого HANDOFF 8.2, **не проводили**. Soniox — варіант за замовчуванням у HANDOFF: підтримує українську, має потоковий API з endpointing, найнижча ціна серед кандидатів, не потребує SDK.
- **Перевірка якості на записі лекції (10 хв, українська):** _заповнити після запуску `spike/stt/stt_spike.py`: модель, час, WER або оцінка на око, типові помилки (терміни, імена, числа)._
- **Що втрачаємо:** немає цифр, які показують, що Soniox кращий за Deepgram чи OpenAI саме на українських лекціях. Якщо якість виявиться незадовільною, архітектура дозволяє замінити `SonioxTranscriber` іншим нащадком `TranscriberBase` (HANDOFF 8.2).
