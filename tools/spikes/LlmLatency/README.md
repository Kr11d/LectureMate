# Спайк M0: затримка LLM українською

Мета (HANDOFF §16, бюджет §4.1): порівняти час до першого токена (TTFT) і загальний час відповіді OpenAI та Anthropic у сценарії S2, коли матеріали курсу йдуть кешованим префіксом. Проєкт окремий і **не входить** у `LectureMate.sln`. Висновок записуємо в `RETROSPECTIVE.md` (розділ «Спайк M0»).

## Запуск

Ключі беруться лише зі змінних середовища `OPENAI_API_KEY` і `ANTHROPIC_API_KEY`. Провайдер без ключа пропускається.

```powershell
$env:OPENAI_API_KEY = "<ключ>"       # лише для поточної сесії PowerShell
$env:ANTHROPIC_API_KEY = "<ключ>"
dotnet run --project tools/spikes/LlmLatency -c Release
```

Без мережі: `--dry-run` показує структуру запиту. Усі параметри: `--help` (кількість запусків, моделі, reasoning effort, режим thinking, власні матеріали).

Повний прогін за замовчуванням: 10 запусків × 3 запити × 2 провайдери = 60 запитів по ~16–20 тис. вхідних токенів, орієнтовно $0,05–0,10.

## Що і як міряємо

| | |
|---|---|
| Запит | system (§12, режим `Auto`) → матеріали курсу (кешований префікс) → «Останні 3 хв лекції: …» і «Питання: …» |
| Запуск | На початку префікса новий ідентифікатор набору матеріалів, тому перший запит запуску гарантовано холодний (`Cold`); наступні `--warm` запитів (типово 2) мають той самий префікс (`Warm`). Питання щоразу інші |
| TTFT | Від виклику SDK до першого непорожнього текстового фрагмента |
| Total | До кінця потоку |
| З'єднання | Перед замірами один короткий запит на провайдера відкриває HTTPS-з'єднання, тож рукостискання TLS не потрапляє в `Cold` |
| Порядок | Провайдери чергуються після кожного запуску, щоб коливання мережі зачіпали обох |
| p50 / p90 | Лінійна інтерполяція між рангами |
| Кеш | OpenAI кешує префікс автоматично (`cached_tokens`); в Anthropic `cache_control` стоїть на блоці матеріалів (`cache_read_input_tokens`, `cache_creation_input_tokens`) |
| NO_Q | Скільки відповідей дорівнюють `NO_QUESTION`. Усі питання справжні, тож очікуємо 0 |

Моделі за замовчуванням (перевірено в документації 28.10.2026): `gpt-6-luna` з `reasoning_effort: none` і `claude-haiku-5-5` з вимкненим thinking. Обидві коштують $0,10 / $0,50 за 1 млн вхідних / вихідних токенів, тож порівняння чесне за ціною.

## Результати

У консолі рядок на кожен запит і підсумкова таблиця. Файли `out/results-*.csv` (лише час і токени) та `out/answers-*.md` (тексти відповідей для оцінки якості на око) ігноруються git і не комітяться.

## Матеріали

`data/*.md` — конспект курсу ООП (8 лекцій, ~47 тис. символів, маркери `[стор. N]`), написаний для спайку за допомогою ШІ (див. `AI_USAGE.md`). `--materials ШЛЯХ` підставляє власну теку з `*.md` або один файл, наприклад текст, витягнутий із PDF курсу.
