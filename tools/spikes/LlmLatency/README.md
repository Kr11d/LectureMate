# Спайк M0: затримка LLM українською

Мета (HANDOFF §16, бюджет §4.1): порівняти час до першого токена (TTFT) і загальний час відповіді Gemini, OpenAI та Anthropic у сценарії S2, коли матеріали курсу йдуть кешованим префіксом. Проєкт окремий і **не входить** у `LectureMate.sln`. Висновок записуємо в `RETROSPECTIVE.md` (розділ «Спайк M0»).

## Запуск

Ключі беруться лише зі змінних середовища `GEMINI_API_KEY`, `OPENAI_API_KEY` і `ANTHROPIC_API_KEY`. Провайдер без ключа пропускається.

```powershell
$env:GEMINI_API_KEY = "<ключ>"       # лише для поточної сесії PowerShell
dotnet run --project tools/spikes/LlmLatency -c Release -- --provider gemini --delay-ms 2000
```

Без мережі: `--dry-run` показує структуру запиту. Усі параметри: `--help` (провайдери, кількість запусків, моделі, reasoning effort / thinking, пауза між запитами, власні матеріали).

Повний прогін: 10 запусків × 3 запити на провайдера, по ~16–20 тис. вхідних токенів. На безкоштовному рівні Gemini це $0; для платних OpenAI і Anthropic орієнтовно $0,03 на провайдера.

Gemini викликається напряму через `HttpClient` (`streamGenerateContent?alt=sse`), без SDK: для спайку новий NuGet-пакет не потрібен. Ключ передається заголовком `x-goog-api-key`, а не в URL.

## Що і як міряємо

| | |
|---|---|
| Запит | system (§12, режим `Auto`) → матеріали курсу (кешований префікс) → «Останні 3 хв лекції: …» і «Питання: …» |
| Запуск | На початку префікса новий ідентифікатор набору матеріалів, тому перший запит запуску гарантовано холодний (`Cold`); наступні `--warm` запитів (типово 2) мають той самий префікс (`Warm`). Питання щоразу інші |
| TTFT | Від виклику SDK до першого непорожнього текстового фрагмента |
| Total | До кінця потоку |
| З'єднання | Перед замірами один короткий запит на провайдера відкриває HTTPS-з'єднання, тож рукостискання TLS не потрапляє в `Cold` |
| Порядок | Провайдери чергуються після кожного запуску, щоб коливання мережі зачіпали обох |
| p50 / p90 | Лінійна інтерполяція між рангами |
| Кеш | Gemini і OpenAI кешують префікс автоматично (`cachedContentTokenCount`, `cached_tokens`); в Anthropic `cache_control` стоїть на блоці матеріалів (`cache_read_input_tokens`, `cache_creation_input_tokens`) |
| NO_Q | Скільки відповідей дорівнюють `NO_QUESTION`. Усі питання справжні, тож очікуємо 0 |

Моделі за замовчуванням (перевірено в документації 28.10.2026): `gemini-3.6-flash` з `thinkingLevel: minimal` (повністю вимкнути thinking у Gemini 3.x не можна; `gemini-3.5-flash-lite` у першому прогоні не влучав у кеш і раз помилково відповів `NO_QUESTION`), `gpt-6-luna` з `reasoning_effort: none` і `claude-haiku-5-5` з вимкненим thinking. OpenAI і Anthropic коштують однаково, $0,10 / $0,50 за 1 млн вхідних / вихідних токенів.

Безкоштовний рівень Gemini має ліміти запитів за хвилину і в години пікового навантаження відповідає `503 UNAVAILABLE`. Такі відповіді рахуються як помилки (стовпець `ok/n`), а не повторюються, бо частка збоїв теж є результатом спайку. `--delay-ms` додає паузу після кожного запиту. Google може використовувати дані безкоштовного рівня для покращення своїх моделей, тож справжні матеріали курсу й транскрипти лекцій туди краще не надсилати.

## Результати

У консолі рядок на кожен запит і підсумкова таблиця. Файли `out/results-*.csv` (лише час і токени) та `out/answers-*.md` (тексти відповідей для оцінки якості на око) ігноруються git і не комітяться.

## Матеріали

`data/*.md` — конспект курсу ООП (8 лекцій, ~47 тис. символів, маркери `[стор. N]`), написаний для спайку за допомогою ШІ (див. `AI_USAGE.md`). `--materials ШЛЯХ` підставляє власну теку з `*.md` або один файл, наприклад текст, витягнутий із PDF курсу.
